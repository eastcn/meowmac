# 桌面猫使用 Codex 宠物

- 目标：桌面猫可以换成本机 Codex 宠物（`$CODEX_HOME/pets`，默认 `~/.codex/pets`）。宠物素材只读，不复制，不进仓库。
- 规划与执行：Claude Opus 5.5，用户 2026-10-25 在对话中确认
- 结果文档：`docs/plans/2026-10-25-codex-pet/result.md`

## 前提

D45 写明桌面猫“只用现有的奔跑帧和严重睡姿，不新增姿态”。本 plan 新增宠物的待机、等待和趴倒动作，需要用户修改 D45。用户在对话中直接要求实现，执行者不改 `docs/DECISIONS.md`，修订建议写在 result。

## 已定

| 编号 | 内容 |
| --- | --- |
| P1 | 来源：只读扫描 `$CODEX_HOME/pets`，未设置时用 `~/.codex/pets`。设置里列出可用宠物直接选，不提供导入。宠物被删或损坏时回到当前猫，设置里写原因。 |
| P2 | 配置：`config.json` 的 `desktopCat.pet` 存宠物目录名，缺省表示跟随当前猫。即时生效，同 D45 其余字段。 |
| P3 | 格式：`pet.json` 读 `id`、`displayName`、`spritesheetPath`、`spriteVersionNumber`，其余字段忽略。图集 PNG 或 WebP，每格 192×208，8 列；v1 为 1536×1872（9 行），v2 为 1536×2288（11 行，后两行朝向不用）。`spritesheetPath` 只能是目录内的单个文件名；目录和文件不能是符号链接；`pet.json` 不超过 64 KiB，图集不超过 16 MiB。 |
| P4 | 状态映射：严重 → `failed` 行里可见范围最扁的一格（通常是趴下或倒地），静止；提醒 → `waiting` 行循环，不染色；正常且负载低于 30% → `idle` 行；正常且负载不低于 30% → `running-right` 行。帧计数跟随应用唯一的帧计时器，帧间隔按 D11。减少动态效果时定格当前行第 1 帧，拖动时同样定格。 |
| P5 | 不做：桌面猫的速度线；朝向行；导入或复制宠物；新增计时器或采集。 |
| P6 | 2026-10-25 用户追加：菜单栏也可用宠物，默认与桌面猫共用形象，也可单独选。`config.json` 的 `menuBarPet` 为 `{"source":"desktop"}`（缺省）、`{"source":"cat"}` 或 `{"source":"pet","pet":"<目录名>"}`，坏值回退为 desktop 并记诊断。入口在设置“猫”栏。菜单栏只用向右跑行和倒地格；正常保留原色，提醒整只染橙，严重染红加 zz 并停止，速度线同彩色猫（D11、D12）。两处用同一只时只加载一次。 |
| P7 | 2026-10-25 用户追加：菜单栏宠物放大到 22 pt 高；新增“宠物动画速度”（`petAnimationSpeed`，0.5×～3×，默认 1.6×），菜单栏和桌面猫的宠物共用。不新增计时器：猫和宠物共用帧计时器，各自按时间累计计帧，计时间隔不短于 1/30 秒。 |

## 条目

1. Core：`CodexPet.swift`（清单解析、图集布局、状态映射），`DesktopCatConfig.pet` 字段的读写、坏值回退。
2. UI：`CodexPetLibrary` 列出与加载（安全读取、解码、按格统计非空帧）；`DesktopCatImage` 按宠物绘制；设置分组增加“形象”选择。
3. 自测：清单与布局、坏包拒绝（路径、符号链接、尺寸）、状态映射、配置往返、渲染非空和缓存。夹具在测试中合成，不使用真实宠物。
4. 文档：SPEC「桌面猫」同步；result 写验证结果和 D45 修订建议。

## 验收

- `scripts/check.sh` 通过。
- 安装后选 `~/.codex/pets` 里的宠物，桌面猫显示该宠物并按负载在坐和跑之间切换；选“跟随当前猫”恢复原样。实机外观由用户验收。
