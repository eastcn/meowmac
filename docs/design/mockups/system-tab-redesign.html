系统页重新设计

问题：提醒状态下固定区约 278 pt，内容可视区约 540 pt。现有的诊断卡（约 110 pt）和五行趋势图（约 340 pt）放在一起，能耗排行几乎被挤出首屏。传感器卡和趋势图的温度、风扇两行重复。

两个方案都去掉“传感器”卡片：GPU 温度和最热核心并入温度那一项，诊断卡改紧凑。红色虚线是 820 pt 面板的首屏底边，斜纹区需要滚动。数据均为虚构，HTML 只模拟材质。

共同改动
· 删除 system.sensors 功能块。已保存的布局里如有该块，读取时自动去掉，其余不变。
· 能耗诊断每个问题一行：进程名、类型、数值和持续时长。AI 提示保留为一行小字。
· 温度一项：主值是 SoC 平均温度，副信息写“最热 x · GPU y”，图里画 SoC 和电池两条线。读不到时显示“—”，不单独占卡片。
· 风扇一项：副信息写“静止”或“最大值的 N%”，达到降温条件时转橙色；本机没有风扇时这一项不出现。
· 指标的量程不再单独写一列，改到悬停提示和快照里；时间刻度和底色带图例保留。
