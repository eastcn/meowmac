# MeowMac 独立视觉稿：静谧玻璃

这版方案把总览做成固定的仪表条，正文按分节平铺。玻璃感集中在外壳、选中控件和设置菜单。数据区保持稳定的底色和文字对比度。

设计依据是 `docs/design/BRIEF.md`。未打开 `docs/design/SPEC.md` 和 `docs/design/mockups/`。参考了指定的 CodexBar 截图，也参考了 [Apple 的 Liquid Glass 设计入口](https://developer.apple.com/documentation/technologyoverviews/liquid-glass)。截图中的账号和数据没有复制到本稿。

## 如何查看

直接打开 `index.html`，可并排比较 7 张画板。窄窗口改为纵向排列，每张画板仍为 360px。顶部按钮切换整页浅色和深色。点击画板标题打开单页。

每个 HTML 都包含自己的 CSS、SVG 和主题切换脚本。没有远程字体、图片、脚本、样式或第三方依赖。`index.html` 内嵌全部画板，不需要通过 iframe 加载其他文件。页面之间只有本地导航链接。

这些是静态视觉稿。主题切换和页面导航可用；时间范围只展示选中样式。刷新、清理、访达和设置菜单项不执行系统操作。开机启动展示关闭状态。

| 文件 | 画板内容 |
| --- | --- |
| `system.html` | 正常总览、四条系统趋势、能耗前 5 名、磁盘与清理入口 |
| `system-alert.html` | 失控进程置顶、降温提示、橙色问题标记和排行 |
| `quota-codex.html` | 四渠道切换、账号、每周窗口、节奏刻度、两次重置机会、趋势、花费和存储 |
| `quota-claude.html` | 5 小时和 7 天窗口、两种节奏、累计曲线、窗口峰值柱、花费和存储 |
| `network.html` | 总体结论、五项检查、三组站点、三个出口 IP |
| `settings-menu.html` | 从底栏上方弹出的设置菜单，含全部六项 |
| `menubar-cat.html` | 六帧原创剪影、实际大小的正常／提醒／严重状态，以及高负载动画 |

## 尺寸与排版

HTML 中 1px 对应设计的 1pt。面板宽 360px，最大高 820px。顶部总览、标签页和底栏固定，正文独立滚动。正常系统页将四条趋势、五个进程和磁盘完整放入 820px；异常系统、额度和网络页允许滚动。焦点进入正文后可用键盘滚动。

| 项目 | 规则 |
| --- | --- |
| 字体 | SF Pro Text、PingFang SC；无系统字体时由浏览器选本地字体 |
| 数字 | 所有数据使用等宽数字 `tabular-nums` |
| 正文 | 12px，行高 1.5 |
| 分节标题 | 13px，字重 650 |
| 渠道名称与网络结论 | 16px，字重 650 |
| 关键数值 | 17～22px，字重 600 |
| 次要说明 | 11px；紧凑指标、坐标和底栏时间为 10px |
| 面板内边距 | 左右 17px，加外边框后可用宽度 324px |
| 分节间距 | 常规上下 16px；系统页上下 12px |
| 行内间距 | 6～10px；正文长句允许换行 |
| 圆角 | 外壳 22px，选中渠道和提醒 10～12px，菜单 14px |
| 进度条 | 总览和渠道 3px，窗口及存储 5px；圆角端点 |
| 分隔线 | 1px，按浅深色使用不同透明度 |
| 猫 | 30 × 18px 画布；六帧列表放大 2 倍便于审阅 |

没有使用单行省略号或隐藏文字的裁切。页面外层隐藏滚动条的占位，避免在 360px 窗口内挤压画板；正文保留细滚动条。滚动容器边缘经过的文字会自然离开可视区，横向文字保持完整。

## 三个关键取舍

**1. 玻璃感与可读性。** 外壳和操作层保留透明、模糊和边缘高光，正文提高底色不透明度。牺牲强烈的背景透视，换取每天多次查看时稳定的文字对比度。

**2. 信息完整与首屏密度。** 总览始终显示四个数字指标，系统正常态压缩到一屏。额度页保留账号、节奏、趋势、花费和存储，采用正文滚动。避免为了塞进首屏而缩小主文字或省略字段。底栏始终可见，用户能看出额度缓存的更新时间。

**3. 趋势关联与图表辨识。** 系统四个量采用同轴的四条小图，分别标单位和范围，温度偏高底色贯穿四行。长周期额度画累计已用；5 小时窗口每个窗口画一根峰值柱。牺牲同图叠线的紧凑感，换取单位清楚、时间可对照，也避免重置造成的锯齿。

## 状态与数据含义

- 正常系统页不显示能耗诊断。异常页的第一块是 `BTLEServer` 单核占用 98%、持续 12 分钟，并提示“建议用 AI 诊断”。睡眠断言和持续内存压力采用同一结构：问题名、对象或压力数值、持续时间和诊断提示。
- 总览内存显示已用比例和容量，压力只由底线颜色表达。网络显示下行与上行速率，检测结论只由底线颜色表达。它们的文字状态留在对应详情页。
- 标签上有状态点。原生打开面板时按问题最严重的一类选页，都正常则恢复上次选择。静态画板固定展示各自的标签，不实现健康判定。
- 渠道切换区的 72%、61%、84% 和 46% 表示各渠道主窗口的剩余量。A／B／C／D 都是占位符，不是品牌 logo。仅 Claude 和 Codex 绘制详情。
- 额度条的填充是实际剩余，细刻度是按时间节奏应剩。Claude 的 7 天窗口实际剩 43%，应剩 62%，差值是 19 个百分点，避免把百分点误写成百分比增幅。
- 趋势的纵轴都是已用百分比，和窗口条的“剩余”方向不同，因此图注明确写“累计已用”或“最高已用”。末尾曲线对应 Codex 已用 39%、Claude 已用 57%；5 小时末柱为未结束窗口，已用 28%。
- 花费柱表示每日估算花费的相对变化，柱图不显示精确金额读数。两个汇总金额旁边都保留 token 数，下面注明“按 token 估算，不是账单”。
- 存储只提供分段占用、会话数量和“在访达中显示”。清理仅在磁盘分节提供入口。没有结束进程或删除数据的操作。
- 猫有六帧奔跑剪影。每帧间隔由负载映射：`0.5 − 0.45 × 负载` 秒。提醒只改变整只猫的颜色；严重时显示红色伏卧单帧；负载达到 70% 加三道速度线。减少动态偏好下定格。

所有示例时间都以虚构的 9 月 30 日 14:35 为观察时刻。邮箱只有 `you@example.com`；所有 IP 均来自文档地址段 `203.0.113.0/24`。没有采集真实账号、进程、网络或额度数据。

## 检查记录

2026-09-30 在浏览器中逐个打开 8 个 HTML，使用 360 × 1000px 视口，逐页检查浅色和深色，共 16 种组合。单页截图在 `previews/`，浏览器测量在 `checks.json`。

- 每个面板宽 360px，高度不超过 820px。
- 最终横向溢出检查和行内元素重叠检查均为 0。逐页查看截图，浅深色正文、说明文字和图表都可辨认。
- 长页滚动检查覆盖系统排行与磁盘、两渠道的花费与存储、Claude 的窗口峰值柱，以及网络出口 IP。固定总览和底栏保持可见。
- 总览页在 360px 下纵向排列，在桌面宽度下并排排列，使用与单页相同的画板尺寸。
- 修正了首次检查发现的外层滚动条占宽、Claude 指标标题过宽，以及额度曲线终点与已用比例不一致。
- HTML 模拟材质和系统原生 Liquid Glass 的最终效果仍需在原生实现阶段验收。本次交付是候选视觉稿。
